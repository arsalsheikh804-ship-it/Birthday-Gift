ISRA BIRTHDAY SURPRISE — GITHUB PAGES

1. Extract this ZIP.
2. Upload index.html and the entire assets folder to the root of a GitHub repository.
3. On GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the published URL shown in Settings > Pages.

Keep the assets folder next to index.html. The two cropped cartoon images are separate files inside assets/.
